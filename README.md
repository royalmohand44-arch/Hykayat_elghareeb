# MR1 — حكايات الغريب 3.0

نسخة ثابتة متعددة الصفحات مبنية بـ HTML + CSS + JavaScript Modules، جاهزة للنشر على Vercel أو GitHub Pages بدون بناء أو تثبيت حزم.

## الصفحات
- `index.html` — الرئيسية
- `story.html` — الحكاية وأدوات القراءة وحفظ موضع التقدم
- `characters.html` — الشخصيات والشهادات
- `timeline.html` — خط أحداث تفاعلي من 11 محطة مع تصفية
- `analysis.html` — التحليل الأدبي
- `review.html` — مراجعة بأسئلة مقالية وإجابات قابلة للفتح
- `quiz.html` — اختبار تفاعلي من 10 أسئلة مع حفظ التقدم والنتيجة

## البنية
- `css/`: 16 ملف تصميم أساسي + 7 ملفات خاصة بالصفحات.
- `js/`: وحدات مستقلة للمكونات والتنقل والتخزين والبحث والحركة والقراءة والاختبار والصفحات.
- `assets/`: الخط، الأيقونات، الرسوم المتجهة، والخلفيات.

## التشغيل
افتح `index.html` عبر خادم محلي أو ارفع محتويات المجلد إلى جذر مشروع Vercel. بما أن المشروع يستخدم JavaScript Modules، يفضّل عدم فتحه عبر `file://` مباشرة.

خادم محلي سريع: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## الخط
الخط موجود في `assets/fonts/TheYearofTheCamel-Bold.otf.ttf` (OpenType/CFF) ويُستخدم في النصوص والعناوين.
